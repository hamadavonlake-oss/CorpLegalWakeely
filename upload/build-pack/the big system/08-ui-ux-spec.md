# UI/UX Specification

Arabic RTL and English LTR. Use Next.js, React, TypeScript, Tailwind, shadcn/ui, next-intl and CSS logical properties.

## Navigation
Dashboard; Requests; Matters; Contracts; Documents; Templates; Approvals; Deadlines; Search; Reports; Organization; Settings; Subscription.

## Core screens
1. Login/MFA.
2. Organization onboarding and country pack.
3. Dashboard.
4. Request intake wizard.
5. Request detail.
6. Matter workspace.
7. Contract workspace.
8. Document/version viewer.
9. Approval inbox.
10. Template/clause manager.
11. Search results.
12. Audit log.
13. Export/import.
14. Subscription/admin.

Use progressive disclosure, clear statuses, completion indicators, confirmation for destructive actions, draft watermark, and no internal legal notes visible to requesters.
